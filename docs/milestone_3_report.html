1. Objective & Scope Alignment

Milestone 3 integrates the core Vector Space Model (VSM) backend implemented in Milestone 2 (vsm_engine.py) with an interactive user-facing Command-Line Interface (cli.py, fulfilling FR9), and conducts intermediate empirical evaluation of retrieval relevance, score distributions, tie-breaking determinism, and query latency (NFR1, NFR3, NFR5).

Note on SDMS Template Mapping: The generic SDMS milestone text references a web "Lost & Found" form and admin dashboard from an image-retrieval template. Consistent with our approved Milestone 1 specification, our project is a first-principles text Information Retrieval engine written exclusively in Python's standard library. Its user interface is an interactive real-time CLI supporting ad-hoc search queries, corpus inspection (:docs), schema inspection (:schema), top-k configuration (:top <k>), and JSON persistence (:save).

5. Intermediate Evaluation Findings

  • Relevance Accuracy: cat mat matched the hand-calculated Section 4.5 score (0.5000) exactly; multi-term CS queries surfaced only the two semantically overlapping documents (doc_id=3 and doc_id=4).
  • Determinism (NFR1 / I7): Exact score ties (doc_id=3 and doc_id=4 both scoring 0.3333, as well as zero-scoring documents) were consistently ordered by ascending doc_id.
  • Zero-Crash Robustness (FR8 / NFR3): Empty and completely out-of-vocabulary queries returned 0.0000 cleanly with zero exceptions.
  • Latency Motivation for Milestone 4: Even at N = 8, the dense scan averaged ~1.31 ms/query versus 0.01–0.10 ms via inverted index—motivating full sparse-index optimization and scaling benchmarks in Milestone 4.
